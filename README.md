Amazon Sales Analytics Dashboard 📊

📌 Project Overview
This project focuses on analyzing  Amazon sales transaction data to gain insights into sales performance, profitability, category trends, and regional contribution.  
The goal of this project is to transform raw sales data into an interactive and business-ready Power BI dashboard that helps stakeholders make data-driven decisions quickly.

This project is designed from a Data Analyst perspective, emphasizing KPIs, trends, and actionable insights rather than just visualizations.

🎯 Problem Statement
Amazon generates large volumes of sales data across multiple categories and regions.  
However, raw transactional data alone does not provide clear visibility into:
- Overall sales and profit performance
- Category and product-level contribution
- Regional performance
- Time-based growth trends

The challenge is to convert this raw data into a structured, KPI-driven dashboard that enables faster and better business decisions.

 🛠 Tools & Technologies Used
- Power BI – Data modeling, DAX, and dashboard creation  
- Power Query– Data cleaning and transformation  
- Excel – Source dataset  
- DAX – KPI and measure calculations  





📂 Dataset Description
The dataset contains Amazon sales transaction records with the following key fields:
- Order Date  
- Ship Date  
- Product Name  
- Category  
- Geography  
- Sales  
- Quantity  
- Profit  
This dataset represents transaction-level e-commerce sales data, suitable for sales and profitability analysis.

📈 Key KPIs Used
The following business KPIs were defined and calculated using DAX:

- Total Sales
- Total Profit
- Total Quantity Sold
- Profit Margin (%)
- Month-over-Month Sales Growth (%)
- Average Order Value (optional)
These KPIs align with real-world e-commerce and business intelligence standards.

📊 Dashboard Structure
The dashboard is divided into three main pages

1️⃣ Executive Overview
- KPI Cards (Sales, Profit, Quantity, Profit Margin)
- Sales Trend over Time
- Sales and Profit by Category
- Interactive slicers for Category, Geography, and Year
Purpose: Provide a quick, high-level view of business performance.

2️⃣ Product & Category Analysis
- Product-level performance table
- Top 10 products by sales
- Sales vs Profit scatter analysis
- Category-wise profitability comparison
Purpose: Identify high-performing and underperforming products and categories.

3️⃣ Geography & Time Insights
- Sales by Geography (Map)
- Month-over-Month Sales Growth trend
- Category performance over time (Matrix)
- Quantity trend analysis
Purpose: Understand where and when the business performs best.

🔍 Key Insights
- A small number of categories contribute the majority of total sales.
- Some products generate high revenue but have low profit margins, indicating pricing or cost inefficiencies.
- Sales performance varies significantly across regions.
- Month-over-month growth highlights seasonal patterns and demand fluctuations.
- High sales volume does not always translate into high profitability.
✅ Conclusion
This project demonstrates how raw sales data can be transformed into meaningful business insights using Power BI.  
By defining clear KPIs, applying proper data modeling, and designing intuitive visualizations, the dashboard enables stakeholders to monitor performance, identify problem areas, and support data-driven decision-making.

This project reflects real-world data analyst responsibilities, including data preparation, KPI definition, visualization, and insight generation.
